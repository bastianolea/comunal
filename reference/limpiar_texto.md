# Eliminar puntuación, símbolos y números de textos

Eliminar puntuación, símbolos y números de textos

## Uso

``` r
limpiar_texto(texto)
```

## Argumentos

- texto:

  Vector de texto

## Valor

Vector de texto sin puntuación, símbolos y números, en minúsculas y sin
acentos

## Ejemplos

``` r
limpiar_texto("Ñuñoa")
#> [1] "nunoa"
```
